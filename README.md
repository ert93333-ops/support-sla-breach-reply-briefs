# Support SLA Breach Reply Briefs

Static MVP for checking pasted public-safe SLA/ticket/incident notes before a missed-SLA customer update goes out.

## Offer

Paste support notes. Generate a copyable customer reply brief and internal escalation handoff covering:

- missing customer impact summary
- missing SLA tier or promise
- missing timeline or breach duration
- missing plain-language cause
- missing apology or ownership tone
- missing next update time
- missing remediation owner
- unresolved escalation path
- credit/refund/internal review ambiguity
- risky blame, jargon, or overpromise language
- missing internal follow-up decision

## Conversion Path

Payments are not connected. The MVP uses early-access, demo-request, and purchase-intent capture with a public-safe GitHub issue handoff.
